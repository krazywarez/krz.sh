#+title: krz.sh

* what
source for krz.sh, the krz website. built with [[https://gitbay.org/krz/orgo][orgo]].

* develop
#+begin_src sh
orgo serve content -o /tmp/krz-preview
#+end_src

open http://127.0.0.1:3000.

* build
#+begin_src sh
./build.sh
#+end_src

output goes to public/. build.sh runs =orgo build --strict=, then
versions asset urls by content hash, sets the footer year and lists
directory urls in sitemap.xml.

* structure
#+begin_example
content/         pages, one directory index per url; orgo.toml is the config
templates/       minijinja templates
templates/data/  the services list and unreleased apps, as template literals
static/          assets, main.css, favicon.svg, og.png
assets/          logo sources; assets/build.sh regenerates the icons
#+end_example

* deploy
pushing main runs .githooks/pre-push, which runs build.sh and
rsyncs public/ to homelab:/var/www/krz.sh/. the sync uses --delete,
so the remote mirrors public/ exactly.

git does not clone hooks. enable them once per checkout:

#+begin_src sh
git config core.hooksPath .githooks
#+end_src

cloudflare fronts krz.sh and caches static assets for a year. build.sh
cachebusts the asset urls in templates/base.html so changes propagate;
anything else needs a manual purge.
